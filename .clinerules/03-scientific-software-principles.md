# Scientific Software Principles

This project is a scientific bioinformatics application. Correctness matters more than speed of delivery.

- Scientific correctness is more important than speed of implementation.
- Never invent biological data, accession records, database responses, sequence values, metadata, or analysis results.
- Clearly distinguish retrieved data from calculated data.
- Keep database retrieval separate from analysis logic.
- Keep analysis functions deterministic whenever possible.
- Important scientific calculations must have automated tests.
- Document assumptions and algorithms used for biological metrics.
- Preserve provenance for analysis results whenever practical.
